Sources & what's covered

Listings are collected automatically twice a day from the sources above. Some venues only publish their next few days (Odessa, Volkshotel, offbeat), so they look thin further out. Always check the venue's own page before you go. "Add to calendar" opens an .ics file made by ics.agical.io; the event's name, venue, description and link are sent to that service to build the file.

A small non-commercial hobby project: no ads, no tickets, no tracking. Every event links to its original listing. Map © OpenStreetMap contributors.
